NOTA DE ENGENHARIA — v4.01

Objetivo
- consolidar a portabilidade do núcleo relacional da Jornada sem transformar Microsoft Fabric em dependência de desenvolvimento.

Evidência Fabric
- execução externa em SQL Database in Microsoft Fabric: 58/58 Integration PASS, 0 falhas, 0 skips, 4m48s reportados;
- o cenário concorrente de oito Processor contenders passou após correção do teste para manter o vencedor até todos concluírem a tentativa de aquisição;
- as falhas intermediárias observadas eram de autenticação/harness e estado residual do banco de teste, não de incompatibilidade funcional do núcleo SQL;
- o harness final usa Device Code Flow, reset seguro Test/Dev/Local e validação autoritativa do TRX.

Arquitetura
- `OperationalSqlAdapter` permanece único;
- SQL Server 2022 local/Testcontainers é a baseline obrigatória para desenvolvimento, CI e validação ordinária;
- SQL Database in Microsoft Fabric é alvo adicional homologado, não requisito permanente;
- nenhuma credencial/connection string Fabric integra a release;
- produção não é decidida apenas por compatibilidade: requer benchmark comparativo com carga representativa.

Governança
- Fabric só deve ser testado contra banco dedicado Test/Dev/Local disponibilizado para homologação;
- desenvolvimento/build/testes ordinários não exigem conta, workspace, capacidade ou credencial Fabric;
- escolha de produção deve considerar desempenho, escalabilidade, disponibilidade, custo, segurança, operação e infraestrutura disponível.

Sem mudança funcional/normativa
- Base Normativa v3.62 e SolutionSchema v3.68 permanecem intactos;
- DDL, seed, contratos e dependências NuGet não mudam;
- não há branch funcional por hospedagem.

Validação da v4.01
- o ambiente de empacotamento não dispõe de dotnet/Docker/PowerShell;
- a evidência Fabric recebida valida o conjunto funcional consolidado no harness, mas a release v4.01 deve ser revalidada localmente com `scripts/local-validate-release.ps1` após instalação.
