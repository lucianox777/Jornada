# Família de Requisitos - Jornada do Cidadão - Fase 1

Esta pasta concentra os baselines de requisitos da Fase 1. Use `00_Indice_Mestre_Requisitos_Jornada_v1.0` como porta de entrada e `05_Matriz_Rastreabilidade_Requisitos_Jornada_v1.0` para análise de impacto.

A autoridade normativa superior passa a ser a Especificação Técnica Jornada v3.63 e seus anexos vigentes. Os baselines RN/RF/RNF/RT desta pasta foram emitidos contra a v3.62 e permanecem preservados para rastreabilidade; onde houver divergência arquitetural introduzida pela v3.63, prevalece a Especificação Técnica v3.63 até a próxima rebaseline formal da família de requisitos.
