Mudanças da v3.80:

2. Test seam explícito de readiness: ISqlReadinessProbe/SqlSchemaReadinessProbe separam o contrato HTTP do probe SQL real.

5. Warnings de confiabilidade observados no primeiro build real foram corrigidos: cultura invariável, comparação ordinal, DisposeAsync/base, paramName, defaults e cache de JsonSerializerOptions.
6. .NET analyzers passam a fail-closed: CodeAnalysisTreatWarningsAsErrors=true. Exceções puramente estilísticas/micro-otimização são documentadas e versionadas em .editorconfig, sem renomear códigos de contrato nem romper abstrações.

Limite importante:
- testes Unit/OpenAPI runtime são sem SQL;
- testes Integration/FaultInjection continuam usando SQL Server real por desenho, porque validam semântica T-SQL, transações, locks, constraints e concorrência.
